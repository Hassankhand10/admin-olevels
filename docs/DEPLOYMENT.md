# Deployment

## Build

The production build is generated by:

```bash
npm run build
```

Vite outputs the application to `dist`.

## Firebase Hosting

`firebase.json` configures `dist` as the Hosting directory and rewrites all routes to `/index.html` for SPA navigation. General routes use no-cache headers; static assets use long-lived immutable cache headers.

`.firebaserc` selects the Hosting project `admin-olevels`.

## Production configuration

The production environment uses `VITE_BASE_URL`, `VITE_API_BASE_URL`, and `VITE_USE_EMULATORS` from `.env.production`. Values are intentionally not reproduced here.
