# OLevels Admin Portal

The OLevels Admin Portal is a React/TypeScript/Vite single-page application for administrative monitoring, grading, reporting, AI-assignment review, Realtime Database inspection, and checker-usage reporting.

The app is hosted through Firebase Hosting but uses the shared OLevels Firebase/data project and the main OLevels teacher authentication/session flow. It has no backend source code in this repository.

See the [documentation index](docs/README.md) for architecture, local development, authentication, data schemas, APIs, deployment, security, and release information.
